## `// preview`

> interface gráfica dark com display duplo — expressão + resultado

```
╭─────────────────────────╮
│              2 + 2 =    │  ← expressão
│                    4    │  ← resultado
├──────┬──────┬──────┬────┤
│  C   │  ⌫   │  %   │  ÷ │
│  7   │  8   │  9   │  × │
│  4   │  5   │  6   │  − │
│  1   │  2   │  3   │  + │
│ +/−  │  0   │  .   │  = │
╰──────┴──────┴──────┴────╯
```

---

## `// features`

- display duplo — mostra a expressão e o resultado separados
- operações básicas — `+` `−` `×` `÷` `%`
- suporte completo ao teclado
- tratamento de erros — divisão por zero, expressões inválidas
- visual dark minimalista

---

## `// keybinds`

| tecla | ação |
|-------|------|
| `0-9` | números |
| `+ - * /` | operadores |
| `Enter` | calcular |
| `Backspace` | apagar |
| `Esc` | limpar |

## `// instalação`

**requisitos:** Python 3.x (tkinter já vem incluído)

```bash
# clone o repositório
git clone https://github.com/weareghosst/calc

# entre na pasta
cd CALCULADORA CLEITON

# rode
python CALCULADORA CLEITON.py
```
